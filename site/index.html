Open-source NFC trust and actions

A tap you can trust that can do anything.

Knura checks that every tap came from a genuine NTAG 424 DNA tag, and only then runs the action you set up for it: a webhook, a smart-home routine, your own code. On your own server or in the cloud.

How it works

Every tap is checked before anything happens.

A plain NFC sticker holds a link anyone can copy. A Knura tag proves itself on every tap, so a copied, forged or reused link gets refused.

  1. The tag signs the tap

    NTAG 424 DNA tags use Secure Dynamic Messaging: each tap they encrypt their ID and a counter that goes up by one, and sign it with an AES key that never leaves the chip.

  2. knurd checks it

    The verification daemon works out that tag's own key, checks the signature, and refuses any counter it has already seen. Counters are saved, so a restart doesn't reopen old links.

  3. knurgN runs the action

    Only verified, first-time taps reach the actions engine. It looks up the rule for that tag's ID; nothing in the link can pick or change what runs.

AnswerHTTPWhat happened
ok200Genuine tag, new counter. The action runs.
replay409The link was opened before, for example from browser history or a screenshot.
rejected403Bad signature or unknown tag: a forged or edited link.
malformed400Not a tap link at all.

The pieces

Small programs that each do one job.

Written in Java 21, with no third-party libraries in the crypto or the daemon. The tag code is tested byte for byte against traces from a real tag.

Library

knura-core

The tag crypto: tap verification, per-tag keys and the NTAG 424 DNA commands.

Command line

knurctl

Sets up tags on a USB NFC reader such as the ACR122U: writes Knura's keys and the tap link, then reads it back to check.

Daemon

knurd

Answers tap links over HTTP, with replay protection. Phones get a small "Tap verified" page.

Actions engine

knurgN

Decides what each verified tap does and delivers it, with retries and a 30 second cutoff so nothing runs late.

Actions

Start with a webhook or your smart home.

Every action is signed with the Standard Webhooks format, so the thing receiving a tap can tell it came from your Knura. The Matter bridge shows each tag as a contact sensor, so a tap can start a routine in apps you already use.

Self-hosting

Your taps, your server.

knurd runs the same on a home computer as on a cloud server. A phone needs an HTTPS address to reach it; on a home computer a free tunnel such as Tailscale Funnel gives you a fixed one without opening your router.

# make a master key, then set up a tag on the reader
knurctl init
knurctl provision

# check a tap the way a phone does
knurctl tap

# answer taps from phones
sudo tailscale funnel --bg 8424

Security

Built so one lost tag doesn't cost you the rest.

A key for every tag

Each tag's keys are worked out from one master key and the tag's ID (NXP AN10922). Copying the keys out of one tag doesn't help with any other.

Secrets stay put

Webhook secrets live in their own file that Knura refuses to read if other users can. They never appear in logs.

Tested against the spec

Verification is pinned to NXP's published examples and the RFC 4493 CMAC test vectors.

Careful with what a tap can do

Locks, garage doors and alarms are left out on purpose for now. Taps start everyday actions, not ones that open your home.
